FocusFlow 05 · Core Features
Section 05
Core Features — Detailed Specification
Seven AI-powered modules. One seamless experience.
🔐
Auth
User Authentication
Secure JWT-based register/login/logout with bcrypt hashing, refresh tokens, password reset via email, and optional Google OAuth 2.0.
  • JWT access token (15 min) + refresh token (7 days)
  • httpOnly cookie storage — XSS protected
  • Google OAuth sign-in for frictionless onboarding
  • SendGrid password reset emails
✅
Tasks
Task Manager
Full CRUD tasks with priorities, categories, due dates, sub-tasks, recurring tasks, and a drag-and-drop Kanban board.
  • Kanban board (To-Do / In-Progress / Done)
  • Priority tags: High · Medium · Low
  • Category filters: Work · Study · Personal
  • Bulk actions, sub-tasks, recurring tasks
🤖
AI
AI Goal Breakdown
Type any big goal — AI returns phase overview, weekly milestones, and daily action steps, automatically saved as tasks.
  • Claude Sonnet 4.6 with chain-of-thought prompt engineering
  • Accepts deadline + context for personalisation
  • One-click: accept, edit, or regenerate any step
  • Rate-limited per tier (3/month free · unlimited Pro)
📄
AI
Document Summariser & Flashcard Generator
Upload PDF or paste text. AI returns executive summary, key bullets, and Q&A flashcards — with study mode and Anki export.
  • LangChain PDF loader + text splitter
  • 300-word summary + 5–10 key points + flashcards
  • Flip-card study mode built in
  • Export to PDF summary or Anki deck (.apkg)
⏱️
Focus
Pomodoro Focus Timer
Evidence-backed 25/5 focus cycles with automatic session logging, productivity streaks, and desktop notifications.
  • Link each session to a specific task
  • Streak counter — consecutive days with ≥1 Pomodoro
  • Customisable intervals (Pro feature)
  • All sessions feed into the Analytics Dashboard
📊
Analytics
Analytics Dashboard + Weekly AI Digest
Interactive charts showing productivity trends. Every Sunday, AI generates a personalised coaching report with 3 specific improvements for next week.
  • GitHub-style focus hours heatmap
  • Category distribution pie chart
  • Weekly completion bar chart
  • AI Digest: delivered in-app + email every Sunday

Section 08–09
Platform & Access Decision
✅ Build as PWA Web App (MVP)
  • Works on every device — no install required
  • No App Store approval delays
  • Installable to home screen like a native app
  • Google-indexable for organic SEO
  • One codebase — faster to ship
  • Near-zero distribution cost
📱 React Native App (Post-MVP)
  • Once 1,000+ active web users
  • Reuse same Express API layer
  • iOS App Store + Google Play presence
  • Better offline & native hardware access
  • Estimated: Month 11 of roadmap
